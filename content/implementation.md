## System architecture

Graph carriers contain finite typed members, typed predicate declarations, and directed incidences carrying original evidence. A predicate declaration describes the three type domains and a graph cut binds their membership. Pure incidence queries, sites, restrictions and gluing retain those occupants. SignCell's source predication and aperture structures stay locally owned. SignChain owns evidence ordering and proof prerequisites. Metrologic supplies combinatorial and exact-number operations. The address system supplies content identity. Callers supply transport, authentication, storage, and resources. SignCraft schedules work and receives witnessed graph projections.

A typed mark may explicitly carry a source occurrence or refer to its native SignCell occurrence. Equal displays across distinct identified marks remain distinct, and distinct edge witnesses produce distinct incidences with the same endpoints. A projected shortest path establishes reachability along selected directed incidences. A gluing obstruction establishes incompatibility of supplied declaration data at that predicate. Both concern the finite supplied cut. A partial graph projection discards obstructed content, so a receiving caller must retain the full collection and obstruction receipt for subsequent gluing.

## High-level and low-level design

Normalize constructor inputs once at the source data boundary, with plain records and dense arrays. Verify SCA identity and reconstruct untrusted cuts before use. Index each admitted graph once per process and use the same indexed reference and query admission for every local reader. Store the exact portable carrier separately from cached indexes. Bind a cursor to the graph and the caller's exact selection. Typed Content publishes the schema for the roadmap reader and SignGraph owns structural admission.

A Port is a frozen presentation value with a finite set of admitted kinds and symmetric irreflexive independence pairs. Published independence licenses quotienting the order of those reported observations. Graph source evidence binds a Port to the native ingress boundary. Store each reported delivered message with the original envelope and attributed witness. Use SignCell's reducer and its receipt at the caller boundary. Keep order constraints between dependent messages at that Port and use Metrologic for a canonical topological reading of the trace. Composition compares matching Port identities, unions source cells and message occurrences, and refuses contradictions in occurrence or order. Exact resource custody is represented by a resource identity, a debit, a credit, and the caller-supplied source witness. Metrologic equality and nonnegativity qualify that recorded exchange.

Core work systematizes structural admission and normalizes duplicate query paths. Port composition architecturalizes the first missing channel effect. The Operations Graph and Software Inventory consumers move to Computer Text Content for DOT or Mermaid rendering using the Metrologic graph projection. The roadmap receives the graph schema from Typed Content.
