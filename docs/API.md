## Verified acceptance cases

Specification basis. Sign family rebuilding plan, SignGraph retains relations over cells. Path composition joins matching endpoints and retains the order of predicate labels.

| Case | Check | Behavior |
| --- | --- | --- |
| ` SG-PATH-LOOP ` | source invariant | A single generating loop composes with itself in one round. |
| ` SG-PATH-COORDINATE ` | source refusal | Sixfold lattice transport refuses a fractional coordinate. |
| ` SG-PATH-QUICKSTART ` | consumer example | One round retains both generating edges and records their ordered composite. |

Runtime requirement. ` >=24.2.0 `
